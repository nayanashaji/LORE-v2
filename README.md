# LORE v2

Live demo:- https://lore-v2.vercel.app

LORE is a digital archive dedicated to preserving local folklore and oral traditions — stories passed down through generations that are often lost over time.

Many cultural stories exist only through word of mouth, making them difficult to document and preserve. LORE aims to provide a platform where these narratives can be explored, shared, and remembered, helping keep memories, traditions, and regional histories alive.

This project is the second iteration of LORE.

The first version was my very first website, built during a hackathon. After learning core JavaScript concepts and improving my understanding of web development, I rebuilt the project from scratch to create a more structured, scalable, and interactive experience.
